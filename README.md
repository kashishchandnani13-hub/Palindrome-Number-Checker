# Palindrome Number Checker
A simple program that checks whether a given number is a palindrome. This repository contains implementations in both C and C++.

## Features
1. Checks if a number is a palindrome
2. Implemented in both C and C++
3. User-friendly console input and output
4. Demonstrates number manipulation and looping concepts

## Files
1. palindrome.c – C implementation
2. palindrome.cpp – C++ implementation

## Technologies Used
1. C
2. C++
3. Loops
4. Conditional Statements
5. Arithmetic Operations

## Learning Outcomes
1. Understanding of loops and control structures
2. Number reversal logic
3. Problem-solving using basic programming concepts
4. Comparison of C and C++ implementations
